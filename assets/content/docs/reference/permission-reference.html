  • coretoolsx.admin — operator-default aggregate for reload, inspect, fixitem and bypass.
  • coretoolsx.admin.reload, .inspect, .fixitem.

Skins

coretoolsx.skin.* aggregates wood, stone, copper, iron, gold and diamond skin nodes.

Upgrades

coretoolsx.upgrade.* aggregates wood_to_stone, stone_to_copper, copper_to_iron, iron_to_gold and iron_to_diamond nodes.

Usage locks

coretoolsx.use.* aggregates wood, stone, copper, iron, gold, diamond and netherite nodes. Usage checks run only when locks and blocks.usage are enabled. Definition permissions and usage prefix can be changed in YAML.
