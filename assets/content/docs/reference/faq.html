What does CoreToolsX require?

Paper/Minecraft 1.21.11+ and Java 21+.

Does it require Vault, PlaceholderAPI, a database or CoreArmorX?

No. It also needs no GUI library or custom-item plugin.

Is a resource pack mandatory?

No. It is required only for REAL_TIER; default VISUAL_SKIN is pack-free.

Do normal upgrades receive plugin data?

No. Normal upgraded tools remain material-driven vanilla items.

Which types are supported?

Sword, pickaxe, axe, shovel, hoe and spear.

Where is progression stored?

CoreToolsX stores none; locks are permission-based.

What follows a normal YAML edit?

Run /coretoolsx reload and review warnings.
