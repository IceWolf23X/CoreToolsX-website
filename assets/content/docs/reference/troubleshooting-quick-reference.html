Plugin does not enable

Confirm Paper/Minecraft 1.21.11+, Java 21+, the correct JAR and complete startup logs.

A recipe appears but will not craft

Use separate one-item ingredient slots. Check definition enablement, groups, permissions, already-skinned bases and custom-item protection.

A direct vanilla recipe still works

Check the override, reload and warnings. Wooden crafting and diamond-to-netherite smithing are intentionally untouched.

A REAL_TIER item has a missing model

Install/enable the matching CoreToolsX addon. Use VISUAL_SKIN if no resource pack should be required.

Reload does not change an existing item

Reload affects new/refreshed items. Use /coretoolsx fixitem on a recognized skinned item when appropriate.

A custom item is blocked

The safe default rejects foreign PDC. Do not use REPLACE_ANYWAY until compatibility is understood.
