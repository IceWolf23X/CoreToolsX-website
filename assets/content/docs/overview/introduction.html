CoreToolsX is a Paper-only vanilla+ tool progression plugin for Minecraft/Paper 1.21.11 or newer and Java 21 or newer. It uses normal crafting and vanilla item behavior instead of custom menus, economies or databases.

Two item models

Normal upgraded tools use their Bukkit material as the source of truth and receive no CoreToolsX persistent data. Skinned netherite tools store their clean material, visual skin, original lore state, inventory model mode and optional cosmetic durability in Paper persistent data.

Supported tools

Swords, pickaxes, axes, shovels, hoes and spears participate in the default upgrade, skin and cost model.

Standalone scope

CoreToolsX does not require Vault, PlaceholderAPI, a database, a GUI library, CoreArmorX or a custom-item plugin. The resource pack is optional and used only for REAL_TIER inventory models.

Conservative defaults

  • Progression locks are disabled.
  • Skin durability is disabled.
  • Fire/lava skin stripping is disabled.
  • Foreign persistent data blocks transformations.
  • VISUAL_SKIN requires no resource pack.
