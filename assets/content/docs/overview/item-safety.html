CoreToolsX preserves supported data while changing tool materials: custom name, original lore, enchantments, durability damage, max damage where supported, repair cost, flags, compatible custom data and non-CoreToolsX persistent data.

Foreign custom data

BLOCK_IF_DETECTED is the safe default. REPLACE_ANYWAY permits transformations with foreign PDC and should be used only after compatibility is understood.

CoreToolsX identity

Only skinned tools and internal skin state carry CoreToolsX identity. Normal upgraded tools remain ordinary vanilla items.

Inspection and repair

/coretoolsx inspect reports the held item’s current and clean materials, skin, model mode, lore snapshot and durability. /coretoolsx fixitem reapplies the configured profile/display to a recognized skinned tool; it is not a generic item converter.
