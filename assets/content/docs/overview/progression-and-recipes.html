CoreToolsX routes protected direct tool crafting through configurable upgrade definitions. The bundled path is wood → stone → copper → iron → diamond, with iron → gold as an alternate endpoint.

Default routes

  • WOOD → STONE
  • STONE → COPPER
  • COPPER → IRON
  • IRON → DIAMOND
  • IRON → GOLD

Supported tools and costs

Swords, pickaxes, axes, shovels, hoes and spears are supported. VANILLA_RECIPE_COST uses 1 for shovel/spear, 2 for sword/hoe and 3 for pickaxe/axe. CUSTOM reads a positive count.

Recipe model

Ingredient groups accept configured Bukkit materials. Runtime matching requires separate one-item ingredient slots. Static recipe-book entries aid discovery while runtime validation checks the real item, metadata, cost and permission.

Protected vanilla recipes

With override enabled, protected direct outputs use matching minecraft:* keys. Wooden tool crafting and vanilla diamond-to-netherite smithing remain untouched. Original recipes return when override is disabled or the plugin stops.

Upgrade durability

Outputs can REFILL, KEEP_DAMAGE or KEEP_PERCENTAGE; repair cost preservation is separately configurable.
