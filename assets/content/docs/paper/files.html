CoreToolsX generates four administrator-facing files in plugins/CoreToolsX/.

Runtime folder

The folder contains only the four YAML defaults below. The optional resource pack is distributed separately.

config.yml

Global model, recipe, ingredient, upgrade, lore, removal, stripping, locks and custom-item safety settings.

tool-upgrades.yml

Named progression routes with source/target tiers or materials, ingredients, costs and permissions.

tool-skins.yml

Named netherite skins and optional cosmetic durability.

messages.yml

MiniMessage text for commands, crafting, progression and inspection.

Not public configuration

The resource pack is a separate addon. plugin.yml stays inside the JAR. Neither is synchronized as public configuration.
