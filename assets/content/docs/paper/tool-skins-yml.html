This file defines netherite visual skins and optional cosmetic durability.

Skin definition schema

skins.<id> supports enabled, display-name, ingredient, cost-mode, positive custom count and permission. Defaults are wood, stone, copper, iron, gold and diamond.

Cosmetic durability schema

  • skin-durability.mode: DISABLED|GLOBAL|BY_SKIN|BY_ITEM.
  • global.max-durability.
  • by-skin.{default-max-durability,materials.<skin>}.
  • by-item.default-max-durability and by-item.materials.<skin>.{default-max-durability,sword,pickaxe,axe,shovel,hoe,spear}.
  • damage.{mode,multiplier}; mode currently only MIRROR_REAL_DAMAGE.
  • on-break, currently only REMOVE_SKIN.
  • mending.mode: DISABLED|SPLIT|DOUBLE.
  • placeholders.{disabled-value,bar-segments,bar-full,bar-empty}.
