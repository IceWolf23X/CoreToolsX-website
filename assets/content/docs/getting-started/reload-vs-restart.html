Safe with /coretoolsx reload

The command reloads all four YAML files, rebuilds validated definitions, removes/re-registers recipes, and normalizes skin fire-resistance policy on online players’ items.

  • Runtime toggles and recipe-book behavior.
  • Upgrade/skin definitions and messages.
  • Permission strings stored in YAML and lore templates.
  • Inventory model and cosmetic durability for newly created or subsequently refreshed skinned items.

Restart required

  • Replacing the JAR.
  • Changing Paper/Minecraft runtime.
  • Recovering from startup/classloading errors.
  • Clean-boot validation after broad edits.

Resource pack changes

Changing the optional pack ZIP does not require a server restart. Players must reload or reselect the pack client-side.

Existing files are not merged

Reload does not add new packaged keys to existing YAML. Compare installed files with synchronized defaults after upgrades.
