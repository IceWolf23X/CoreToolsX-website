Requirements

  • Paper/Minecraft 1.21.11 or newer.
  • Java 21 or newer.
  • The CoreToolsX JAR from Modrinth.

Download

Use the public Modrinth project for stable builds. The private plugin source repository is not a download or documentation endpoint.

Installation flow

  1. Stop Paper.
  2. Place CoreToolsX-2026.1.2.jar in plugins/.
  3. Start once and review configuration warnings.
  4. Edit plugins/CoreToolsX/*.yml.
  5. Run /coretoolsx reload.

Generated files

plugins/CoreToolsX/
├── config.yml
├── tool-upgrades.yml
├── tool-skins.yml
└── messages.yml

The resource pack is a separate client addon; it is not generated in this folder. plugin.yml is internal JAR metadata, not server configuration.
