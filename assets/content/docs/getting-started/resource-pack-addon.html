The CoreToolsX resource-pack addon is required only when tool-skin.inventory-model.mode: REAL_TIER. The default VISUAL_SKIN mode needs no pack.

What the pack changes

CoreToolsX stores the skinned tool as its visual vanilla material and assigns item_model: coretoolsx:skinned/<material_tool>. The addon shows netherite in GUI, ground, fixed and shelf contexts while keeping the visual skin in hand. Without the pack, a REAL_TIER item has a missing/invalid custom model.

Separate distribution

The addon comes from the plugin repository’s top-level resource-pack/ source and must be packaged/distributed separately. It is not a runtime YAML file and is excluded from private configuration synchronization.

Pack format

Current metadata starts at resource format 84.0 and accepts later 84.x minor formats. Review the pack before widening support to a later major format.

Client refresh

After replacing the pack, players must reload or reselect it. No server restart is required for the ZIP itself.
